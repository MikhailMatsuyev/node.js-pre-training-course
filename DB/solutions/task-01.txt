########### 2. Connect to the database

Command:

psql -U postgres -h localhost -d todo_app

The database was successfully opened:

todo_app=#


########### 3. Create the todos table

The todos table was created using raw SQL.

CREATE TABLE todos (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL CHECK (TRIM(title) <> ''),
    description TEXT,
    status TEXT NOT NULL DEFAULT 'active',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

Result:

CREATE TABLE

The table contains:

id — auto-incrementing integer primary key.
title — required text field; empty titles are not allowed.
description — optional text field.
status — required text field with active as the default value.
created_at — timestamp automatically set to the current time.


########### 4. Verify the table structure

Command:

\d todos

The database confirmed the following structure:

id          integer                     not null
title       text                        not null
description text
status      text                        not null
created_at  timestamp without time zone not null

The table has a primary key on id and a check constraint preventing an empty title.

########### 7. Test the title constraint

An empty title was tested:

INSERT INTO todos (title, description, status)
VALUES ('', 'Test empty title', 'active');

PostgreSQL rejected the record:

ERROR: new row in relation "todos" violates check constraint "todos_title_check"

This confirms that the title field cannot contain an empty string.
