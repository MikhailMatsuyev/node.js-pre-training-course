Task 07: ORM Setup
ORM

Prisma 6.19.0 was selected as the ORM for the PostgreSQL Todo application.

Prisma was configured separately in the DB directory.

Database connection

The existing PostgreSQL database todo_app was connected through .env:

DATABASE_URL="postgresql://postgres:1@localhost:5432/todo_app"

The Prisma schema is located at:

prisma/schema.prisma

The existing database structure was introspected using:

npx prisma db pull

Prisma detected the existing users and todos tables.

Prisma models

The schema defines two related models:

User — application users
Todo — todo items belonging to a user

The existing PostgreSQL table names are preserved using @@map("users") and @@map("todos").

The relationship is:

User 1 ──── * Todo

The existing index on todos.status and the foreign key todos.user_id → users.id are also represented in the Prisma schema.

Migrations

Because the database and its tables had already been created during Tasks 01–06 using raw SQL, a baseline migration was created instead of recreating the existing tables.

The baseline migration was marked as already applied:

npx prisma migrate resolve --applied 00000000000000_init

Migration status:

1 migration found in prisma/migrations
Database schema is up to date!

No database reset was performed and existing data was preserved.

Prisma Client

Prisma Client was generated with:

npx prisma generate
Seed

A seed.js script was created using Prisma Client.

The seed creates:

2 users
3 todos for each user
active and completed todo statuses

The seed was executed with:

node seed.js

The result was verified through Prisma Client:

Alice → 3 todos
Bob   → 3 todos
