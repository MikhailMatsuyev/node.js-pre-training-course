## 1. Count Todos by Status

SELECT status, COUNT(*) AS todo_count
FROM todos
GROUP BY status;

  status   | todo_count
-----------+------------
 active    |          5
 completed |          2
(2 rows)

The query groups todos by their status and counts the number of records in each group.
## 2. Count Todos per User

Query:
SELECT
users.name,
COUNT(todos.id) AS todo_count
FROM users
JOIN todos ON todos.user_id = users.id
GROUP BY users.id, users.name;

Result:
 name | todo_count
------+-----------
 John |          2
 Anna |          2
(2 rows)

The query joins users with todos and counts the todos assigned to each user.
Users without todos are not included because an INNER JOIN is used.

## 3. Find Users with No Todos

Query:

SELECT
users.name,
users.email
FROM users
LEFT JOIN todos ON todos.user_id = users.id
WHERE todos.id IS NULL;

  name   |        email
---------+---------------------
 Mikhail | mikhail@example.com
(1 row)

## Brief Description
In this task, raw SQL aggregation and grouping were used to generate statistics for the todo-list database.
The following SQL features were used:

* COUNT() for counting records
* GROUP BY for grouping records
* JOIN for connecting users with their todos
* LEFT JOIN for finding users without todos
* WHERE for filtering the result

No ORM or additional libraries were used.
