Database: PostgreSQL
Database name: todo_app

Connect to the database:

psql -U postgres -h localhost -d todo_app

###### 1. Filter by Status

Select all active todos:

SELECT * FROM todos
WHERE status = 'active';

###### 3. Search by Keyword

Search for the keyword "meeting" in both the title and description:

todo_app=# SELECT * FROM todos
todo_app-# WHERE title ILIKE '%meeting%'
todo_app-#    OR description ILIKE '%meeting%';
