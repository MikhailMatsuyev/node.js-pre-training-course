Task 01 — Custom Event Emitter

 In this task, a custom MessageSystem was implemented using the built-in Node.js EventEmitter.

 Implemented:

 sending messages of different types: message, notification, alert;
 subscribing to all messages;
 subscribing to a specific message type;
 support for multiple listeners;
 message history;
 clearing message history;
 getting system statistics;
 adding and removing users;
 getting the list of active users;
 user-joined and user-left events.

 Additionally, the following bonus features were implemented:

 saving message history to a JSON file;
 searching messages;
 rate limiting for user messages.

 The bonus features are also checked by running the demo in task-01.js.
