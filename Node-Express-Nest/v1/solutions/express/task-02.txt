Task 02: Params and Queries Challenge with Validation

Implemented an Express application with validation middleware for route parameters and query parameters.

Validation:

id — must be a positive integer;
active — must be exactly true or false;
validated values are stored in req.validated.

Route:

GET /users/:id?active=true|false

The route returns the user ID, active status, and a corresponding message.
