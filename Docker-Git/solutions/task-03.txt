Task 03: Create and Run Your First Docker Container

1. Dockerfile

FROM node:24-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY app.js ./

EXPOSE 3000

CMD ["npm", "start"]


2. package.json

{
  "name": "docker-node-app",
  "version": "1.0.0",
  "description": "Simple Node.js application for Docker",
  "main": "app.js",
  "scripts": {
    "start": "node app.js"
  },
  "engines": {
    "node": "24.x"
  }
}


3. app.js

const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello Docker!');
});

server.listen(3000, () => {
  console.log('Server running on port 3000');
});


4. Docker commands

Build image:

docker build -t my-node-app:v1 .

Run container:

docker run -d --name my-node-app -p 3000:3000 my-node-app:v1

List running containers:

docker ps

Inspect container:

docker inspect my-node-app

Test application:

(Invoke-WebRequest http://localhost:3000).Content

View logs:

docker logs my-node-app

Stop container:

docker stop my-node-app

Remove container:

docker rm my-node-app

List images:

docker images
