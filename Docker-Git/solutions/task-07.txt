Task 07: Orchestrating Multiple Services with Docker Compose

Project: Docker Compose Node.js API + PostgreSQL + pgAdmin
Node.js: 24.x
PostgreSQL: 16
pgAdmin: dpage/pgadmin4


1. Project structure

Docker-Git/task-07/
├── src/
│   └── index.js
├── Dockerfile
├── .dockerignore
├── docker-compose.yml
├── package.json
└── package-lock.json


2. Node.js API

The Express API provides two endpoints:

GET /health

Response:
{"status":"ok"}

GET /data

Response:
[{"id":1,"name":"First item"},{"id":2,"name":"Second item"},{"id":3,"name":"Third item"}]


3. Dockerfile

FROM node:24-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY src ./src

EXPOSE 3000

CMD ["npm", "start"]


4. Docker Compose configuration

services:
  api:
    build: .
    container_name: task-07-api
    ports:
      - "3000:3000"
    environment:
      DB_HOST: postgres
      DB_PORT: 5432
      DB_NAME: taskdb
      DB_USER: postgres
      DB_PASSWORD: postgres
    depends_on:
      - postgres
    networks:
      - task-07-network

  postgres:
    image: postgres:16
    container_name: task-07-postgres
    environment:
      POSTGRES_DB: taskdb
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
    volumes:
      - postgres-data:/var/lib/postgresql/data
    networks:
      - task-07-network

  pgadmin:
    image: dpage/pgadmin4
    container_name: task-07-pgadmin
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@example.com
      PGADMIN_DEFAULT_PASSWORD: admin
    ports:
      - "5050:80"
    depends_on:
      - postgres
    networks:
      - task-07-network

networks:
  task-07-network:

volumes:
  postgres-data:


5. Docker Compose commands used

Start all services:

docker compose up -d

Check running services:

docker compose ps

View API logs:

docker compose logs api

View PostgreSQL logs:

docker compose logs postgres

View pgAdmin logs:

docker compose logs pgadmin

Stop services gracefully:

docker compose down

11. Docker Compose networking

All three services use the same network:

task-07-network

The API, PostgreSQL and pgAdmin containers can communicate using Docker Compose service names.

For example, PostgreSQL is available to other containers as:

postgres:5432

The API does not currently establish a database connection. PostgreSQL connection parameters were configured through environment variables as required by the task.


12. PostgreSQL data persistence

A named volume was configured:

postgres-data:/var/lib/postgresql/data

The volume was created by Docker Compose:

task-07_postgres-data

The services were stopped with:

docker compose down

The volume was intentionally preserved because the command was used without the -v option.
